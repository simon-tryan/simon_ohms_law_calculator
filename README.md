# simon_ohms_law_calculator
A Python-based Ohm's Law and Electrical Power Calculator.
Simon's Ohm's Law and Power Calculator

What it does

This is a Python calculator designed to calculate voltage, current, resistance and electrical power using Ohm's Law. It also allows users to view their previous calculations.

How to run it

Install Python 3 and run:

"python simon_ohms_law_calculator.py"

Sample output

===== SIMON'S CALCULATOR =====
1. Calculate Voltage
2. Calculate Current
3. Calculate Resistance
4. Calculate Power
5. View Calculation History
6. Exit

Voltage = 10.0 Volts

My own twist

I added a calculation history feature that allows users to view previous results while the program is running.
